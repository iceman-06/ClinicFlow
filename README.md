# ClinicFlow

University project (GNG1103) developed on behalf of CaIot.

- **Live Demo:** https://iceman-06.github.io/ClinicFlow/

## Tech Stack

- **Framework:** Flutter (Dart SDK `^3.14.0`)
- **Backend & Auth:** Firebase Core, Firebase Auth, Cloud Firestore
- **Mapping:** `flutter_map`, `latlong2`
- **UI & Utilities:** `material_ui`, `cupertino_icons`, `url_launcher`

## Getting Started

flutter pub get
flutter analyze
flutter test
